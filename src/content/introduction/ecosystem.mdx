## Product map

| Surface | What it reads | What it can write |
|---|---|---|
| **Swap** | Quotes, balances, allowances, pool reserves and prices | Approval, permit, wrap/unwrap, or swap |
| **Liquidity · Pools** | Indexed V2 and V3 pools: TVL, volume, fees, APR, charts | Opens the add flow or a pool page |
| **Liquidity · My positions** | Wallet V2 LP, V3 NFT positions, farm stakes, pending rewards | Add, remove, collect V3 fees, stake/unstake V2 LP, harvest |
| **Liquidity · Create position** | Pool state, ticks, liquidity distribution, balances | Approval, create/initialize a V3 pool, mint a V3 position, or add V2 liquidity |
| **Earn** | MasterChef and SmartChef pool state | Approval, deposit, withdraw, harvest |
| **Tokens** | Prices, volume and liquidity from BitBlocks pools | Opens prefilled swap or liquidity flows |
| **Dashboard** | Protocol metrics, token prices, wallet balances | Nothing by default |
| **Governance** | Informational roadmap | No live proposal action in the main app |

## Protocol layers

<InfoGrid>
  <InfoCard icon="wallet" title="Interface layer"><p>Next.js, wagmi, viem and RainbowKit connect the browser to BNB Smart Chain. A fallback list of BSC RPC endpoints is configured for reads and transaction tracking.</p></InfoCard>
  <InfoCard icon="route" title="Routing layer"><p>The quote engine probes direct and multi-hop paths through base assets such as WBNB, BUSD, USDT, ETH, BBKFI and WBBK on every venue, then ranks the results by output net of estimated gas.</p></InfoCard>
  <InfoCard icon="layers" title="AMM layer"><p>BitBlocks V2 is a constant-product AMM with fungible LP tokens. BitBlocks V3 is a concentrated-liquidity AMM, forked from PancakeSwap V3, where each position is an NFT with its own price range.</p></InfoCard>
  <InfoCard icon="coins" title="Reward layer"><p>One MasterChef manages many BBKFI pools and is the only BBKFI minter. Separate SmartChef contracts each manage one pre-funded reward schedule over a defined block range.</p></InfoCard>
</InfoGrid>

## Related BitBlocks products

The Finance app is one product in the broader BitBlocks ecosystem:

- [BitBlocks ecosystem](https://bitblockscrypto.com) — the network and project landing site.
- [WBBK bridge](https://bridge.bitblockscrypto.com/) — conversion between BBK and its BNB Chain representation, linked from the app sidebar.
- [BitBlocks explorer](https://explorer.bitblockscrypto.com/) — explorer for the BitBlocks chain.
- [Voting site](https://vote.bitblockscrypto.com/) — a separate ecosystem voting experience.

<Callout type="warning">
  The bridge and vote site are separate applications. Their contracts and behavior are not inferred from the BitBlocks Finance frontend; verify their own prompts and documentation before signing.
</Callout>

## Design boundaries

- The Finance app is configured for **BNB Smart Chain only**.
- Native BNB is represented as WBNB inside AMM paths and pools; direct BNB ↔ WBNB actions use wrap/unwrap logic.
- WBBK V2 is the curated active WBBK asset. WBBK V1 remains searchable but is labeled **deprecated** in the interface configuration.
- BitBlocks V3 fee tiers are **0.01%, 0.05%, 0.3% and 1%**. There is no 0.25% tier, unlike PancakeSwap V3.
- 1inch is optional and only participates when its provider flag and server credential are configured.
- Every route has its own approval spender. The app derives the approval target from the selected quote.
