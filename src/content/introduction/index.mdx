# What is BitBlocks Finance?

BitBlocks Finance is a decentralized finance protocol. It offers a self-custodial, 
permissionless platform where users can swap tokens, provide liquidity and earn staking rewards , all without intermediaries.

## Core Principles

- **Security** — Non-custodial smart contracts audited for safety. Users always control their own funds.
- **Transparency** — All contract code is publicly verifiable on-chain. No hidden fees, no hidden logic.
- **Growth** — Designed to scale. The protocol continuously adds value through liquidity incentives and ecosystem expansion.
