## BitBlocks protocol contracts

<InfoGrid>
  <InfoCard icon="route" title="Router"><p>The user-facing V2 entry point for swaps, adding liquidity, removing liquidity, and native BNB wrapping paths.</p></InfoCard>
  <InfoCard icon="layers" title="Factory and pairs"><p>The factory creates deterministic pair contracts. Each pair holds two reserves, mints LP tokens, and enforces the 0.25% fee-adjusted invariant.</p></InfoCard>
  <InfoCard icon="coins" title="MasterChef"><p>A single farm manager with multiple pool IDs, BBKFI minting, pool weights, deposit fees, reward debt and emergency withdrawal.</p></InfoCard>
  <InfoCard icon="spark" title="SmartChef"><p>Independent single-pool staking contracts with pre-funded rewards, per-block rate, fixed start/end blocks and optional wallet limits.</p></InfoCard>
</InfoGrid>

## External integrations

The quote engine also knows PancakeSwap V2, PancakeSwap V3, and optional 1inch endpoints. These are **not BitBlocks-owned protocol contracts**. A winning external route can change the approval spender and execution target.

| Integration | Used for | Enabled by |
|---|---|---|
| PancakeSwap V2 Router | V2 quote and execution | Included in router registry |
| PancakeSwap Quoter V2 | V3 fee-tier quotes | Included in V3 quote path |
| PancakeSwap Smart Router | V3 execution | Included in V3 quote path |
| 1inch Classic Swap v6 | Aggregated quotes and transaction data | Environment provider flag + server API key |
